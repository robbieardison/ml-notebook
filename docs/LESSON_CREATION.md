# Turning these notebooks into lessons

1. **One notebook ≈ one lab session** (60–90 minutes). Split long notebooks (e.g. credit-risk EDA) across two sessions.
2. **Start from learning objectives** in each `course/*/README.md` and the matching `exercises/module-*.md`.
3. **Live coding:** run the first cells, then hide solutions for exercise portions.
4. **Path discipline:** teach learners to start Jupyter from the **repository root** so `utils.data_paths` works.
5. **Assessment:** use exercise prompts as exit tickets; capstone rubric is in `exercises/module-08-capstone.md`.

For instructor-only notes, duplicate a notebook into a `_instructor` copy if you add answers.
